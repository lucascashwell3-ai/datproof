# Security

Found a security problem in DATproof (the site, the feed or the tool server)? Please report it privately, not in a public issue.

1. Go to the repository's **Security** tab and choose **Report a vulnerability**: https://github.com/lucascashwell3-ai/datproof/security/advisories/new
2. Say what you found, where, and how to see it happen. You will get a reply in the same private thread.
3. If that button is not there, open an issue titled "Security contact" with no details, and a private way to talk will follow.
